# CAD

STL files and the parametric source go here once they exist. Brief for each part (all dimensions are starting guesses; make pill size, servo size and screen size variables at the top):

1. **Dispensing discs (x3):** ~70 mm x 4 mm disc, one pocket near the edge. Pocket diameter = pill diameter + 1 mm; depth a bit under 1.5x pill thickness. Splined/cross hole for an SG90 horn. Optional sweep paddle.
2. **Wide base plate:** holds all three units in a row, three exit holes, merged chute into one cup, servo standoffs.
3. **Servo mounts (x3):** shaft straight up through the disc centre, slots for servo ears.
4. **Hoppers (x3):** steep (>=45 deg) smooth funnel, gap above disc slightly taller than the pill, label area.
5. **Pill cup holder.**
6. **Touchscreen mount and enclosure** (optional).

Print rules: no overhangs over 45 deg without supports, walls >= 1.6 mm, 0.3 mm clearance between moving parts. PETG is better for discs.
